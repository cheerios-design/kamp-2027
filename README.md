# Kamp 2027 Planner

Interactive planner for the 2027 YSA Türkiye hiking-camping conference (Bursa vs Sakarya): trail maps with elevation profiles, drive times from each establishment, gear lists, schedule and theme ideas.

Map data © OpenStreetMap contributors. Elevation: SRTM via Open-Meteo. Province outlines: cihadturhan/tr-geojson.
